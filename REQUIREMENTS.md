# Requirements

Requirements for **maplestoryv83hacks**.

## System

- Windows
- Python 3

## Python dependency

Install the external Python package:

```bash
pip install pymem
```

Or, when using the included `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Included with Python

The scripts also use:

- `ctypes` — Python standard library
- `tkinter` — normally included with the standard Windows Python installation

These do not normally need to be installed with `pip`.
